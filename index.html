FAQ

자주 묻는 질문

채용 마감일 전까지 지원서 수정이 가능합니다. 마이페이지에서 지원 현황을 확인하고 수정하실 수 있습니다.

네, 복수 직무 지원이 가능합니다. 다만 면접 일정이 겹칠 경우 1개 직무만 선택하셔야 합니다.

각 전형별 결과는 해당 전형 종료 후 2주 이내에 이메일과 문자로 안내드립니다. 마이페이지에서도 확인 가능합니다.

온라인 코딩 테스트로 진행되며, 알고리즘 문제 풀이 방식입니다. 사용 가능 언어는 Java, Python, C++, JavaScript 등입니다. 시험 시간은 약 2~3시간이며, 자세한 안내는 서류 합격 시 별도 공지됩니다.

매년 하계/동계 인턴십 프로그램을 운영하고 있습니다. 인턴십 종료 후 우수 인턴에게는 정규직 전환 기회가 주어집니다. 모집 일정은 별도 공지를 확인해주세요.
